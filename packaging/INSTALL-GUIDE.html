✨ 나만의 라이브위키

유튜브 영상을 Claude로 요약해서 크롬 옆 패널에 보여 주는 개인용 도구입니다. (테스트판 · Mac / Windows)

할 수 있는 것
  • 유튜브 영상 아래 ✨ 요약 버튼 → 핵심 3가지 · 아티클 · 타임라인 · 전체 스크립트
  • 뉴스·블로그 글(네이버 블로그 포함)도 요약 → 핵심 3가지 · 아티클 · 구성 · 원문
  • 시간을 누르면 그 장면으로 이동, 스크립트 자동 스크롤
  • 💬 AI 채팅으로 영상 내용 질문하기
  • 섹션별 복사, 원하는 폴더에 마크다운(.md)으로 저장

준비물

필수Mac 또는 Windows 10/11, Google Chrome (Edge·Brave도 가능)
Claude 연결
둘 중 하나		 A. Claude 구독(Pro/Max)이 있는 경우 — 추가 요금 없음. Claude Code를 설치하고 한 번 로그인해 두면 끝(아래 3단계).
B. 구독이 없는 경우 — Anthropic API 키. 쓴 만큼 요금이 나갑니다.

1단계 · 설치 프로그램 실행 (약 3분)

🍎 Mac

  1. 받은 zip 파일을 더블클릭해서 풉니다. → LiveWikiMe 폴더가 생깁니다.
  2. 터미널을 엽니다. (⌘+Space → "터미널" 입력 → Enter)
  3. 아래 한 줄을 복사해 붙여넣고 Enter. (zip을 '다운로드' 폴더에서 풀었을 때) 
    bash ~/Downloads/LiveWikiMe/install.sh
    다른 곳에서 풀었다면 bash 까지 입력한 뒤, 폴더 안의 install.sh 파일을 터미널 창에 끌어다 놓고 Enter.
  4. "🎉 설치 완료!"가 나오면 끝입니다. 프로그램은 홈 폴더의 LiveWikiMe에 설치되고, zip을 푼 폴더는 지워도 됩니다.
"Python이 필요해요"가 나오면 함께 뜨는 '개발자 도구 설치' 창에서 설치를 누르고(5~10분), 끝나면 위 명령을 다시 실행하세요.
더블클릭이 편하다면 install.command를 마우스 오른쪽 클릭 → 열기로 실행해도 됩니다. "확인되지 않은 개발자" 경고로 막히면 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 '그래도 열기'를 누르세요.

🪟 Windows

  1. 받은 zip 파일을 마우스 오른쪽 클릭 → 압축 풀기(모두 추출). (zip 안에서 바로 실행하면 안 돼요)
  2. 풀린 LiveWikiMe 폴더에서 install.bat을 더블클릭합니다.
    • "Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 누르세요.
    • Python이 없으면 자동으로 설치를 시도합니다(winget). 안 되면 열리는 python.org에서 설치하되, 첫 화면의 "Add python.exe to PATH"를 꼭 체크한 뒤 install.bat을 다시 실행하세요.
  3. "🎉 설치 완료!"가 나오면 끝입니다. 프로그램은 C:\Users\내이름\LiveWikiMe에 설치되고, 탐색기로 그 폴더가 열립니다.

2단계 · 크롬에 확장 프로그램 불러오기 (처음 한 번)

  1. 크롬 주소창에 chrome://extensions 입력 (엣지는 edge://extensions)
  2. 개발자 모드 켜기 (크롬은 오른쪽 위, 엣지는 왼쪽 아래)
  3. 압축해제된 확장 프로그램을 로드합니다 클릭 → LiveWikiMe → chrome_extension 폴더 선택
    • Mac: 폴더 선택 창에서 ⌘+Shift+H(홈 폴더) → LiveWikiMe
    • Windows: 주소 칸에 %USERPROFILE%\LiveWikiMe\chrome_extension 입력 → 폴더 선택
  4. 툴바의 퍼즐 조각 아이콘 → '나만의 라이브위키' 옆 📌 를 눌러 고정해 두면 편합니다.

3단계 · Claude 연결 (처음 한 번)

유튜브 영상을 열고 ✨ 요약(또는 툴바 아이콘)을 누르면 오른쪽 패널이 열립니다. 오른쪽 위 ⚙️에서 연결 시험을 눌러 "✅ 연결 성공"이 나오면 끝입니다.

A. Claude 구독(Pro/Max) — 추천, 따로 넣을 것 없음

  1. Claude Code가 없다면 설치합니다.
    • Mac — 터미널 앱에서:
      curl -fsSL https://claude.ai/install.sh | bash
    • Windows — 시작 메뉴에서 PowerShell을 열고:
      irm https://claude.ai/install.ps1 | iex
      Windows에서는 Git for Windows도 필요할 수 있어요. 오류에 "git-bash"가 보이면 설치하세요.
  2. 터미널(Windows는 PowerShell)에서 claude 를 실행해 내 Claude 계정으로 로그인합니다. 이미 Claude Code를 쓰고 있다면 건너뛰세요. (설치 직후 "command not found" / "인식되지 않습니다"가 나오면 창을 닫았다 다시 열고 실행)
  3. 패널 ⚙️ → 연결 시험. "✅ 연결 성공"이면 끝!
연결 시험이 실패할 때만: 구독 토큰 넣기
  1. 맥 기본 '터미널' 앱(Windows는 PowerShell)에서 실행: 
    claude setup-token
    ⚠️ Claude 데스크톱 앱 안의 입력창에서 실행하면 토큰이 •••로 가려져 복사할 수 없어요.
  2. 브라우저에서 승인하면 터미널에 sk-ant-oat…로 시작하는 긴 값이 나옵니다. 끝까지 전부 복사하세요. 맥 터미널에서 드래그로 선택이 안 되면 Fn 키를 누른 채 드래그하세요.
  3. 패널 ⚙️ → 구독 토큰을 펼쳐 붙여넣고 저장 → 자동으로 연결 시험을 합니다.

B. 구독이 없는 경우 — API 키

  1. console.anthropic.com에서 가입·결제 수단 등록 후 Create Key
  2. sk-ant-api… 값을 패널 ⚙️ → API 키에 붙여넣고 저장.
🔒 토큰과 API 키는 내 컴퓨터에만(LiveWikiMe 폴더) 저장됩니다. 비밀번호와 같으니 다른 사람에게 보내지 마세요.

사용법

  • 영상 요약: 영상 제목 아래 보라색 ✨ 요약 → 30초~1분 (긴 강연은 몇 분)
  • 뉴스·블로그 요약: 글을 연 상태에서 툴바의 라이브위키 아이콘 → 패널의 이 글 요약하기, 또는 페이지에서 마우스 오른쪽 클릭 → "라이브위키로 이 페이지 요약" (10~30초). 처음 한 번 크롬이 "웹사이트의 데이터 읽기" 권한을 물으면 허용을 눌러 주세요. 버튼을 눌렀을 때만 그 페이지의 본문을 읽습니다.
  • 탭: 핵심 · 아티클 · 타임라인 · 스크립트 · 💬 AI 채팅
  • 저장: 요약은 먼저 보여 주기만 해요. 💾 저장을 눌러야 파일로 남아요. ▾에서 저장 폴더를 바꿀 수 있어요. (기본: ~/LiveWikiMe/summaries)
  • 복사: 보고 있는 섹션만 복사 / 전체 복사
  • 한 번 요약한 영상은 다시 열어도 바로 나옵니다(사용량 들지 않음). 새로 만들려면 다시 요약.

문제가 생기면

증상해결
"요약기에 연결하지 못했어요"1단계 설치를 다시 실행 → 크롬을 완전히 종료(Mac ⌘Q / Windows 모든 크롬 창 닫기) 후 다시 열기
Windows: "git-bash" 관련 오류Git for Windows 설치 후 다시 시도, 또는 API 키 사용
"로그인되어 있지 않거나 로그인이 만료"터미널(PowerShell)에서 claude 를 실행해 다시 로그인. 그래도 안 되면 구독 토큰 사용
"토큰이 올바르지 않거나 만료" / "가려진 값(•••)"맥 기본 터미널 앱에서 claude setup-token으로 새 토큰을 받아 끝까지 복사해 다시 저장
"자막을 가져오지 못했습니다"자막(자동 자막 포함)이 없는 영상은 아직 요약할 수 없어요
"본문을 거의 찾지 못했어요"로그인해야 보이는 글이거나 글 대부분이 이미지인 페이지예요. 글이 화면에 다 보이는 상태에서 다시 시도해 보세요
"이 페이지를 읽을 권한이 없어요"'다시 시도'를 누르고 크롬이 묻는 창에서 허용
✨ 요약 버튼이 안 보임유튜브 탭 새로고침(⌘R / F5). 그래도 없으면 툴바의 확장 아이콘으로 패널을 열고 '이 영상 요약하기'
"Chrome이 폴더에 접근하려고 합니다"허용을 눌러 주세요 (저장 폴더를 문서·바탕화면 등으로 바꿨을 때)

그래도 안 되면 아래 파일을 보내 주세요: LiveWikiMe/native_host/host.log (Mac: 홈 폴더, Windows: C:\Users\내이름 아래)

테스트 부탁드려요 🙏

  1. 설치는 몇 분 걸렸나요? 막힌 단계가 있었나요?
  2. 영상 3개 이상 요약해 보기 (짧은 영상 · 30분 이상 강연 · 외국어 영상)
  3. 아티클 요약의 품질은 어떤가요? (라이브위키와 비교해 좋은 점 / 아쉬운 점)
  4. 💬 AI 채팅으로 질문 2~3개
  5. 저장 · 복사 · 저장 폴더 바꾸기
  6. 불편했던 점, 있었으면 하는 기능
