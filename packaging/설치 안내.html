✨ 나만의 라이브위키

유튜브 영상을 Claude로 요약해서 크롬 옆 패널에 보여 주는 개인용 도구입니다. (테스트판 · Mac 전용)

할 수 있는 것
  • 유튜브 영상 아래 ✨ 요약 버튼 → 핵심 3가지 · 아티클 · 타임라인 · 전체 스크립트
  • 시간을 누르면 그 장면으로 이동, 스크립트 자동 스크롤
  • 💬 AI 채팅으로 영상 내용 질문하기
  • 섹션별 복사, 원하는 폴더에 마크다운(.md)으로 저장

준비물

필수Mac, Google Chrome (Brave·Edge도 가능)
Claude 연결
둘 중 하나		 A. Claude 구독(Pro/Max)이 있는 경우 — 추가 요금 없음. Claude Code 설치가 필요합니다(아래 3단계).
B. 구독이 없는 경우 — Anthropic API 키. 쓴 만큼 요금이 나갑니다.

1단계 · 설치 프로그램 실행 (약 3분)

  1. 받은 zip 파일을 더블클릭해서 풉니다. → LiveWikiMe 폴더가 생깁니다.
  2. 터미널을 엽니다. (⌘+Space → "터미널" 입력 → Enter)
  3. 아래 한 줄을 복사해 붙여넣고 Enter. (zip을 '다운로드' 폴더에서 풀었을 때) 
    bash ~/Downloads/LiveWikiMe/install.sh
    다른 곳에서 풀었다면 bash 까지 입력한 뒤, 폴더 안의 install.sh 파일을 터미널 창에 끌어다 놓고 Enter.
  4. "🎉 설치 완료!"가 나오면 끝입니다. 프로그램은 홈 폴더의 LiveWikiMe에 설치되고, zip을 푼 폴더는 지워도 됩니다.
"Python이 필요해요"가 나오면 함께 뜨는 '개발자 도구 설치' 창에서 설치를 누르고(5~10분), 끝나면 위 명령을 다시 실행하세요.
더블클릭이 편하다면 install.command를 마우스 오른쪽 클릭 → 열기로 실행해도 됩니다. "확인되지 않은 개발자" 경고로 막히면 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 '그래도 열기'를 누르세요.

2단계 · 크롬에 확장 프로그램 불러오기 (처음 한 번)

  1. 크롬 주소창에 chrome://extensions 입력
  2. 오른쪽 위 개발자 모드 켜기
  3. 압축해제된 확장 프로그램을 로드합니다 클릭 → 폴더 선택 창에서 ⌘+Shift+H(홈 폴더) → LiveWikiMe → chrome_extension 선택
  4. 툴바의 퍼즐 조각 아이콘 → '나만의 라이브위키' 옆 📌 를 눌러 고정해 두면 편합니다.

3단계 · Claude 연결 (처음 한 번)

유튜브 영상을 열고 ✨ 요약(또는 툴바 아이콘)을 누르면 오른쪽 패널에 ⚙️ 설정이 열립니다. 아래 중 하나를 붙여넣고 연결 시험을 누르세요.

A. 구독 토큰 (Claude Pro/Max)

  1. Claude Code가 없다면 터미널에서 설치합니다: 
    curl -fsSL https://claude.ai/install.sh | bash
  2. 터미널에서 아래 명령 → 브라우저가 열리면 내 Claude 계정으로 승인: 
    claude setup-token
    (설치 직후라 "command not found"가 나오면 터미널을 닫았다 다시 열고 실행)
  3. 터미널에 나온 sk-ant-oat…로 시작하는 긴 값을 복사해서 패널 ① 구독 토큰 칸에 붙여넣고 저장.

B. API 키

  1. console.anthropic.com에서 가입·결제 수단 등록 후 Create Key
  2. sk-ant-api… 값을 패널 ② API 키 칸에 붙여넣고 저장.
🔒 토큰과 API 키는 내 Mac에만(~/LiveWikiMe 폴더) 저장됩니다. 비밀번호와 같으니 다른 사람에게 보내지 마세요.

사용법

  • 요약: 영상 제목 아래 보라색 ✨ 요약 → 30초~1분 (긴 강연은 몇 분)
  • 탭: 핵심 · 아티클 · 타임라인 · 스크립트 · 💬 AI 채팅
  • 저장: 요약은 먼저 보여 주기만 해요. 💾 저장을 눌러야 파일로 남아요. ▾에서 저장 폴더를 바꿀 수 있어요. (기본: ~/LiveWikiMe/summaries)
  • 복사: 보고 있는 섹션만 복사 / 전체 복사
  • 한 번 요약한 영상은 다시 열어도 바로 나옵니다(사용량 들지 않음). 새로 만들려면 다시 요약.

문제가 생기면

증상해결
"요약기에 연결하지 못했어요"1단계 설치를 다시 실행 → 크롬을 완전히 종료(⌘Q) 후 다시 열기
"로그인 정보를 찾지 못했습니다" / "토큰이 올바르지 않거나 만료"⚙️ 설정에서 claude setup-token으로 새 토큰을 받아 다시 저장
"자막을 가져오지 못했습니다"자막(자동 자막 포함)이 없는 영상은 아직 요약할 수 없어요
✨ 요약 버튼이 안 보임유튜브 탭 새로고침(⌘R). 그래도 없으면 툴바의 확장 아이콘으로 패널을 열고 '이 영상 요약하기'
"Chrome이 폴더에 접근하려고 합니다"허용을 눌러 주세요 (저장 폴더를 문서·바탕화면 등으로 바꿨을 때)

그래도 안 되면 아래 파일을 보내 주세요: ~/LiveWikiMe/native_host/host.log

테스트 부탁드려요 🙏

  1. 설치는 몇 분 걸렸나요? 막힌 단계가 있었나요?
  2. 영상 3개 이상 요약해 보기 (짧은 영상 · 30분 이상 강연 · 외국어 영상)
  3. 아티클 요약의 품질은 어떤가요? (라이브위키와 비교해 좋은 점 / 아쉬운 점)
  4. 💬 AI 채팅으로 질문 2~3개
  5. 저장 · 복사 · 저장 폴더 바꾸기
  6. 불편했던 점, 있었으면 하는 기능

삭제

터미널에서 bash ~/LiveWikiMe/uninstall.sh 실행 후, chrome://extensions에서 '나만의 라이브위키' 삭제.
